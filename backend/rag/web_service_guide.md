# COWOW 웹 서비스 사용 가이드

이 문서는 현재 React 화면과 백엔드 문서를 기준으로 정리한 사용자용 서비스 안내입니다.

## 로그인과 화면 이동

- 첫 화면에서는 Google 로그인 또는 게스트 로그인을 사용할 수 있습니다.
- 로그인 후 대시보드로 이동합니다.
- 하단 메뉴에서 대시보드, 영상 분석, 소 등록, AI 상담, 환경 제어 화면으로 이동할 수 있습니다.
- AI 상담은 텍스트 질문과 이전 대화 내용을 지원하지만 현재 채팅 화면에서 이미지나 파일 첨부는 지원하지 않습니다.

## 이상 개체 대시보드와 AI 판단 피드백

- 대시보드는 정상, 주의, 위험 개체 수와 최근 이상 알림을 표시합니다.
- 상세 현황에서 전체, 위험, 주의 필터로 이상 개체 목록을 확인할 수 있습니다.
- 프론트 화면은 분석 결과로 받은 상태를 표시하며, 주의와 위험을 나누는 정확한 수치 기준은 프론트 코드에 정의되어 있지 않습니다.
- AI 판단이 잘못됐으면 이상 개체 항목의 `AI 판단이 잘못됐어요` 버튼을 누릅니다.
- `정상인데 이상으로 탐지`, `행동 종류 오류`, `다른 소의 결과 연결`, `판단하기 어려움` 중 문제 유형을 선택하고 필요하면 올바른 행동과 설명을 입력한 뒤 `검토 요청 보내기`를 누릅니다.
- 제출된 피드백은 즉시 학습 정답으로 사용되지 않고 운영자 검토와 승인 후 재학습 자료로 내보냅니다.

## 영상 분석 사용법

- 하단 메뉴에서 `영상 분석`으로 이동합니다.
- `영상 선택`을 눌러 제공된 축사 시연 영상을 선택하고 `영상 분석 시작`을 누릅니다.
- 화면에는 영상 전송, 개체 탐지, 개체 추적, 행동 분석, 분석 완료 순서로 상태와 진행률이 표시됩니다.
- 분석이 완료되면 결과 영상과 탐지된 개체별 분석 결과를 확인할 수 있습니다.
- 다시 실행하려면 `다시 분석하기`, 선택을 취소하려면 `선택 해제`를 사용합니다.
- 현재 화면은 제공된 시연 영상을 선택하는 방식이며 사용자 로컬 영상 파일을 직접 첨부하는 입력은 제공하지 않습니다.

## 소 등록과 귀표 OCR

- 하단 메뉴의 `소 등록`에서 귀표 사진과 비문 사진을 이용해 개체를 등록합니다.
- 귀표 번호가 선명하게 보이는 사진을 선택하면 AI가 귀표 위치를 탐지하고 OCR로 번호를 판독합니다.
- 번호가 자동으로 인식되면 결과를 확인하고, 인식하지 못하면 다른 사진으로 다시 시도하거나 귀표 번호를 직접 입력합니다.
- 귀표 사진을 선택하면 같은 `소 등록` 화면에 `귀표 번호` 입력란이 표시됩니다. 자동 인식 결과가 틀리거나 인식에 실패하면 이 입력란에서 번호를 직접 입력하거나 수정합니다.
- 귀표 사진이 없거나 귀표 번호를 확인하지 않았거나 비문 사진을 한 장도 선택하지 않으면 등록할 수 없습니다.
- 귀표가 화면 중앙에 크고 선명하게 보이도록 촬영하고 흔들림, 거리, 빛 반사를 줄이는 것이 좋습니다.
- 이미지 품질이 낮거나 귀표를 찾지 못하면 다른 사진을 선택해 분석을 다시 실행할 수 있습니다.
- 채팅 화면에는 이미지 첨부 기능이 없으므로 오류 화면이나 귀표 사진을 RAG 채팅에 직접 첨부할 수 없습니다. 표시된 오류 메시지나 오류 코드를 텍스트로 입력하면 관련 절차를 안내받을 수 있습니다.

## 비문 사진 등록

- 소 등록 화면에서 비문 사진을 한 장 이상 선택해야 합니다.
- 여러 비문 사진을 선택하면 사진 간 일치도를 확인한 뒤 비문 임베딩을 등록합니다.
- 사진 일치도가 기준에 미달하거나 비문 API 연결에 실패하면 개체 기본정보 저장을 계속하지 않고 사진을 고쳐 다시 시도하도록 안내합니다.
- 비문은 코 무늬가 잘 보이도록 선명하게 촬영하고 사진 사이에 같은 개체인지 확인할 수 있어야 합니다.

## AI 상담 사용법

- 하단 메뉴의 `AI 상담`에서 한우 관리, 방역 지침, 법령, 서비스 사용법을 텍스트로 질문할 수 있습니다.
- 문서 근거가 충분하면 답변과 함께 참고 문서가 표시됩니다.
- 문서 근거가 부족하면 일반지식 안내 문구와 함께 답하며 참고 문서는 표시하지 않습니다.
- 답변이 출력 토큰 한도에 도달하면 불완전한 마지막 문장을 제거하고 `추가 응답을 원하시면 '이어서 설명해 주세요'라고 입력해 주세요.`라고 안내합니다.
- 후속 질문은 이전 대화 내용과 함께 전송됩니다.
- 긴급한 동물 건강 문제는 AI 답변만으로 판단하지 말고 수의사에게 확인해야 합니다.

## 축사 환경 제어와 장비 연결

- 하단 메뉴의 `환경 제어`에서 등록된 ESP32 게이트웨이와 센서 상태를 확인합니다.
- 장비가 없으면 `장비 등록하기`를 눌러 장비 연결 화면으로 이동합니다.
- 일반 사용자는 장비 본체나 포장지의 COWOW 장비 번호를 입력하고 로그인 이메일로 일회용 등록 코드를 받은 뒤 설치 축사와 코드를 확인해 연결합니다.
- 공유 장비 연결은 관리자가 로그인 이메일로 보낸 일회용 인증 코드를 입력합니다.
- 게스트 사용자는 데모 장비만 임시 연결할 수 있습니다.
- 연결 후 환경 제어 화면에서 온도, 습도, 암모니아 등 센서 상태를 확인하고 자동 또는 수동 모드를 선택할 수 있습니다.
- 수동 모드에서는 환기팬 단계와 물 뿌리기를 직접 제어할 수 있습니다. 자동 모드에서는 수동 조작이 제한됩니다.
- 장비 번호가 잘못됐거나 이메일 정보를 확인할 수 없거나 코드가 없으면 화면의 안내에 따라 번호와 로그인 상태를 다시 확인합니다.

## 자주 발생하는 오류 대응

- 귀표 번호 인식 실패: 귀표가 중앙에 크게 보이는 선명한 사진으로 다시 시도하거나 번호를 직접 입력합니다.
- 귀표 이미지 품질 부족: 흔들림, 거리, 빛 반사를 줄이고 다시 촬영합니다.
- 비문 등록 실패: 같은 개체의 선명한 비문 사진인지 확인하고 사진을 다시 선택합니다.
- 영상 분석 실패: 선택한 시연 영상을 다시 선택한 뒤 분석을 재시도합니다. 계속 실패하면 화면의 오류 메시지를 기록합니다.
- 장비 등록 실패: 장비 번호, 로그인 이메일, 일회용 코드와 설치 축사를 확인합니다.
- 로그인 실패: 로그인 세션을 다시 시작하거나 게스트 로그인으로 서비스 화면을 확인합니다.
- AI 상담에서 더 구체적인 도움이 필요하면 화면에 표시된 오류 메시지와 오류 코드를 텍스트로 입력합니다. 현재 채팅에는 캡처 첨부 기능이 없습니다.
